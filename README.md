### Installation

1. Create new environment: `python -m venv .venv`
2. Activate environment: Windows `.venv\Scripts\activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Download data from `https://physionet.org/content/sleep-edfx/1.0.0/` and copy them to folder `data`.
